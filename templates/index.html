About the Machine Learning model

Random Forest Regressor builds many decision trees on random parts of the data and averages their predictions. It copes well with non-linear patterns (such as evening peaks), is robust to noise and needs little tuning. Features include calendar information (hour, weekday, month, weekend) and past consumption (lags and rolling averages). The test set is always the most recent part of the data, so the model never sees the future during training.
